# Автомобильный каталог

Учебный проект собирает объявления SATAuto и CarHub, хранит исходные данные в PostgreSQL и показывает цены, наличие и характеристики в локальном каталоге. Парсеры используют Scrapy. Ссылки на фотографии сохраняются в базе. Дата и охват загрузки видны в интерфейсе.

## Быстрый запуск

Установите Docker с Compose. В терминале компьютера перейдите в корень проекта и выполните:

```sh
./parse init
./parse
```

Откройте [каталог](http://127.0.0.1:8765/), [аналитику и прогоны](http://127.0.0.1:8765/analytics) или [индекс SATAuto](http://127.0.0.1:8765/?scope=all). Команда `./parse` также запускает контейнеры и сбор. На пустой базе она начнёт с публичной витрины. Для поиска по всему списку адресов выполните `make sitemap`.

| Команда | Результат |
| --- | --- |
| `make parser-run DETAILS=24 BRAND=toyota` | До 24 новых подробных карточек Toyota из сохранённого индекса |
| `./parse list` | Публичная выдача SATAuto с базовыми полями |
| `make parser-resume` | Возобновление загрузки SATAuto с сохранёнными задачами |
| `./parse all` | Обойти подробные карточки всего сохранённого индекса SATAuto в фоне |
| `make parser-status` | Состояние очереди SATAuto и последние ошибки |
| `make carhub` | Публичная проба CarHub в пределах трёх страниц |
| `make trim-build RUN=8` | Справочник комплектаций по сохранённому прогону №8 |
| `make trim-check RUN=4` | Сводка по совпадениям со справочником для прогона №4 |
| `make down` | Остановка контейнеров с сохранением тома PostgreSQL |

Номер прогона берите из сводки команды или из истории в веб-каталоге. Полный список команд выводит `make help`.

## Источники и поля

| Источник | Что сохраняется |
| --- | --- |
| SATAuto, карта сайта | ID, страна, марка, модель и URL опубликованной страницы |
| SATAuto, публичные HTML-страницы | Опубликованные цены, наличие, характеристики и статьи расчёта, когда они присутствуют в карточке |
| CarHub v2, список | Цена продавца, расчёт CarHub и характеристики из JSON списка |
| Согласованный NDJSON-снимок | Поля выгрузки, включая подробные данные и ссылки на медиа |

В интерфейсе цена продавца, предварительный, полный и частичный расчёты подписаны. По умолчанию диапазон и медиана относятся к опубликованной стоимости. Частичный расчёт показан в карточке отдельно. В аналитике можно выбрать тип цены и увидеть, у скольких карточек она известна. Охват полного индекса и охват подробных карточек показаны раздельно.

## Проверка

Требуются Python 3.11 или новее и Docker. Тесты запускают HTTP-стенд на loopback и используют отдельную схему PostgreSQL.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
make test
.venv/bin/python tests/benchmark.py
```

Код сборщика находится в `catalog/`, тесты в `tests/`, сохранённые метрики в `reports/`.
