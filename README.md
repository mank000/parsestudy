# Автомобильный каталог SATAuto

Учебный проект по сбору и анализу автомобильных объявлений. Scrapy загружает данные SATAuto, PostgreSQL хранит объявления и позиции обхода, а веб-каталог показывает характеристики, цены и статус продажи. FastAPI даёт доступ к сохранённым данным через JWT и курсорную пагинацию.

## Быстрый показ

Установите Docker с Compose v2.24 или новее и запустите из корня репозитория:

```sh
./parse demo
```

Откройте [каталог](http://127.0.0.1:8775/) и [аналитику](http://127.0.0.1:8775/analytics). В примере шесть синтетических объявлений из трёх стран. Выберите Японию и статус «В продаже», откройте карточку Toyota Corolla, затем сравните медианы цен по странам в аналитике.

При первом запуске Docker загружает базовые образы и Python-зависимости. Демонстрация использует отдельный том PostgreSQL и работает без запросов к источникам объявлений. Для остановки используйте `./parse demo-stop`.

## Сбор данных

```sh
./parse init
./parse api --country JP --pages 3
```

[Основной каталог](http://127.0.0.1:8765/) и [аналитика](http://127.0.0.1:8765/analytics) используют отдельную рабочую базу. Повторный сбор продолжает с сохранённой позиции. Статусы снятых и проданных автомобилей сохраняются вместе с объявлениями.

| Команда | Действие |
| --- | --- |
| `./parse api --pages 3` | Обработать до трёх страниц выдачи SATAuto |
| `./parse all` | Запустить фоновый обход архива и периодическую проверку новых объявлений |
| `./parse all --country KR --year-min 2020 --year-max 2023` | Ограничить фоновый сбор страной и годом выпуска |
| `./parse status` | Посмотреть курсоры, диапазоны и очередь карточек |
| `./parse logs -f` / `./parse stop` | Следить за журналом или остановить фоновый обход |
| `./parse carhub` | Загрузить отдельную выборку CarHub до трёх страниц |
| `make down` | Остановить основной стек с сохранением данных |

`./parse --help` показывает дополнительные команды для карты сайта, публичных HTML-страниц и справочника комплектаций. После обновления кода повторите `./parse init`, чтобы пересобрать образ. Сервисы доступны только на loopback. Основной PostgreSQL доступен на порту 55432, демонстрационный — на 55433.

### Что доступно в интерфейсе

- Поиск по ID, фильтры по стране, марке, характеристикам, ценам и времени последнего наблюдения.
- Цена продавца, предварительный и полный расчёт, если они доступны у источника.
- Аналитика предложений и полноты карточек по странам, медианные цены и статистика HTTP-запросов сборщика.
- [Swagger и инструкция по настройке JWT](docs/catalog-api.md) для отдельного API на порту 8766.

SATAuto собирается через API витрины и публичные страницы. Ошибки источника могут задерживать обход, полнота текущего архива не подтверждена. Время наблюдения показывает, когда запись последний раз сохранил сборщик. Импорт подготовленного NDJSON и ограниченная выборка CarHub описаны в [руководстве по сбору](docs/scrapy.md).

## Проверки

Для тестов понадобятся Python 3.14 и Docker. Тестовый раннер создаёт временную базу PostgreSQL. В сценариях сбора используются локальные HTTP-стенды.

```sh
python3.14 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
make test
```

GitHub Actions запускает этот набор и проверяет чистый запуск демонстрационного каталога в Docker Compose.
