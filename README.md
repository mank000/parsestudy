# Сбор и анализ автомобильного каталога

Scrapy собирает страницы документированного API CarHub v2. PostgreSQL 17 хранит объявления по прогонам, удаляет дубликаты по ID и рассчитывает показатели для Markdown-отчёта. Поля JSON сохраняются целиком, включая ссылки на фото, галереи и панорамы, когда их возвращает источник. Пауки не загружают медиафайлы. Отдельная команда измеряет охват по sitemap SATAuto.

[Результаты измерений и анализ](reports/RESULTS.md) · [Промпт для продолжения работы](PROMPT.md)

## Запуск

Из корня проекта, с Python 3.11+ и Docker Compose.

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
docker compose up -d --wait
.venv/bin/python -m catalog init
.venv/bin/python -m catalog crawl
.venv/bin/python -m catalog report --run 1
```

Команда `crawl` печатает `run_id`, время, число попыток HTTP и ответов. Используйте выведенный ID в `report --run`. Прогон и отчёт принимают `--output путь`. PostgreSQL по умолчанию доступен на `127.0.0.1:55432`. Для другой базы задайте `DATABASE_URL`.

## Источники

| Задача | Команда | Данные |
| --- | --- | --- |
| Короткая проверка публичного CarHub | `python -m catalog crawl --pages 1` | До 100 объявлений за страницу по умолчанию. Можно указать `--country JP\|KR\|CN` |
| Проверка публичной карты сайта | `python -m catalog sitemap --shards 1` | Число уникальных ID по странам в первом файле |
| Полный подсчёт по опубликованной карте сайта | `python -m catalog sitemap --all --output reports/live-satauto-sitemap.json` | Все файлы из индекса. Карточки, цены и фото не запрашиваются |
| Импорт разрешённой выгрузки SATAuto | `python -m catalog import-export /path/catalog.ndjson` | Полные записи за один снимок, с нулём HTTP-запросов из парсера |
| Согласованный API с контрактом CarHub v2 | `CATALOG_API_ORIGIN=https://approved.example python -m catalog crawl --full` | Заголовок Bearer берётся из `CATALOG_API_TOKEN`, если он задан. Для одного ID делается один дополнительный запрос полной карточки |
| Продолжение прогона на согласованном API | `CATALOG_API_ORIGIN=https://approved.example python -m catalog crawl --resume ID` | Последний сохранённый курсор и уже обработанные карточки берутся из PostgreSQL |

Публичный CarHub предназначен здесь для коротких проб. Его выдача и тарифы могут отличаться от SATAuto. Для полной аналитики по витрине нужен снимок её объявлений или согласованный API с нужным профилем цен и покрытием. Поддержка произвольных контрактов партнёрского API через одну переменную окружения не предполагается. Для NDJSON ожидается одна JSON-запись об автомобиле на строку с числовым `id` и объектами `source`, `listing`, `identity`, `specs`, `pricing`, `media` в формате CarHub. Дубликат ID, пустая выгрузка или ошибка формата отменяют импорт.

## Стоимость обхода

- Список: до 100 записей за один запрос, один курсор за раз. Для 1 000 записей при заполненных страницах нужно 10 запросов к API и один к `robots.txt`.
- Детализация: к запросам списка добавляется один запрос на автомобиль, если полные данные доступны отдельным методом. Если нужны фото и оснащение всех машин, полный пакетный экспорт сокращает этот расход.
- Страницы и курсор фиксируются одной транзакцией. Повторившийся курсор останавливает запуск. При сбое уже записанные страницы остаются в базе и помечаются как частичная выборка.
- Интервал между стартами запросов составляет 1,1 с на источник в рамках запуска. При ошибке HTTP сбор останавливается. При `429` или получении `Retry-After` во время API-прогона срок ожидания сохраняется и проверяется при следующем запуске. Scrapy соблюдает `robots.txt` и не следует редиректам. [Методы, пагинация и лимиты CarHub](https://carhubauto.ru/api/)

## Проверка

```sh
export TEST_DATABASE_URL=postgresql://catalog:catalog-local@127.0.0.1:55432/catalog
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python tests/benchmark.py
```

Интеграционные тесты и замер поднимают HTTP-стенд на loopback и используют отдельную схему PostgreSQL, которую затем удаляют.

## Веб-страница аналитики

```sh
docker compose up -d --build --wait
```

Откройте [каталог](http://127.0.0.1:8765/), [аналитику и историю прогонов](http://127.0.0.1:8765/analytics) или [индекс SATAuto](http://127.0.0.1:8765/?scope=all). После сбора или импорта обновите страницу. На вкладке каждого источника показывается последний прогон с данными, с приоритетом завершённого снимка перед частичным. Если есть согласованная выгрузка SATAuto, она открывается по умолчанию.

Для запуска страницы из локального окружения используйте `.venv/bin/python -m catalog.dashboard --port 8765`. При запущенном контейнере укажите другой свободный порт. Веб-сервер доступен с этого компьютера.

В каталоге доступны поиск по ID, выбор марки и страны, диапазон цен, наличие, сортировка и пагинация. Поле «Какая цена» задаёт сумму для диапазона, сортировки и аналитики. Цена продавца показана отдельно от расчёта до Владивостока. Опубликованная стоимость включает полный или предварительный расчёт либо общую сумму, опубликованную на витрине. Частичный расчёт показывается в карточке и исключён из этого диапазона. Блоки «Цены по странам» и «Цены по маркам» пересчитываются по тем же фильтрам.

```sh
.venv/bin/python -m catalog crawl --pages 3 --output /tmp/carhub-run.json
.venv/bin/python -m catalog sitemap --all --store --output /tmp/satauto-sitemap.json
.venv/bin/python -m catalog public-html --root-only --details 24 --output /tmp/satauto-run.json
```

Эти команды наполняют чистую базу выборкой списка CarHub, индексом SATAuto и карточками публичной витрины SATAuto. На компьютере с готовой базой для запуска демонстрации достаточно Docker Compose. Новый прогон `--root-only` создаёт отдельную выборку SATAuto. Для пополнения текущей выборки воспользуйтесь `--enrich`. Разбор результатов, дата и точный охват опубликованы в [отчёте](reports/RESULTS.md).

Индекс SATAuto содержит адреса из сохранённой карты сайта. Для совпавших ID он показывает данные SATAuto. Недоступные характеристики помечены «Не указано». «По запросу» означает, что источник явно запросил уточнение цены. Фото доступны ссылками.

```sh
.venv/bin/python -m catalog public-html --enrich --make bmw --details 8
.venv/bin/python -m catalog public-html --enrich --make toyota --details 10
```

Команда последовательно читает выбранную порцию публичных HTML-карточек. Она
пропускает уже загруженные адреса и сохраняет каждую запись сразу. При ошибке
доступа завершает запуск и учитывает `Retry-After` перед новым запуском. В метриках сбора указаны количество попыток, статусы ответов, ошибки и принятые байты тел ответов. Для HTTP 503 в JSON указываются путь запроса, тип содержимого и значение `Retry-After`, когда сервер его прислал.
