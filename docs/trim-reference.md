# Справочник комплектаций

Справочник дополняет технические характеристики автомобилей китайского рынка. Ключ состоит из страны, марки, модели, года и названия комплектации. Приведение регистра и пробелов применяется одинаково к объявлениям и справочнику. Для подтверждения нужны совпадающая мощность или объём двигателя, отсутствие разногласий по остальным общим техническим полям и ровно одна подходящая запись.

Карточка показывает только недостающие технические значения с подписью источника. Разрешены объём и мощность двигателя, топливо, привод, коробка передач и тип кузова. Цена, пробег, наличие и цвет автомобиля берутся из объявления.

## Построение по сохранённому прогону

```sh
make trim-build RUN=8
make trim-check RUN=4
```

Для построения учитываются лоты с ID площадки и полным ключом комплектации. Каждое сохранённое значение должно совпасть минимум в двух разных исходных лотах. Группы с противоречивыми техническими данными пропускаются. Справочник хранит номер прогона и подтверждающие ID лотов. Повторная сборка обновляет набор, сформированный по сохранённым объявлениям.

Проверка выводит число совпадений, неоднозначных совпадений и карточек, которым можно добавить хотя бы одно поле. Номера прогонов доступны в веб-истории и в выводе команды сбора.

## Импорт справочника

При наличии согласованного справочника используйте UTF-8 NDJSON с одной комплектацией на строку.

```json
{"reference_source":"Пример поставщика","reference_id":"example-cn-001","source":{"country":"CN"},"identity":{"manufacturer":"Toyota","model":"Camry","trim":"2.0 CVT"},"listing":{"year":2023},"specs":{"engine_displacement_cc":1987,"engine_power_hp":175,"transmission":"CVT"},"source_url":"https://example.org/specifications/001"}
```

```sh
.venv/bin/python -m catalog trim-import /путь/комплектации.ndjson
make trim-check RUN=4
```

При повторном импорте запись обновляется по паре `reference_source, reference_id`. Ошибка формата или дубликат ключа в одном файле отменяют весь импорт. Ссылки на источник опциональны.
