# API каталога

Swagger: http://127.0.0.1:8766/docs. OpenAPI: `/openapi.json`.
API читает PostgreSQL и не обращается к SATAuto при клиентских запросах.
Включены все сохранённые объявления выбранного прогона, включая неактивные.
Адресный индекс sitemap без данных объявления в API `/cars` не подмешивается.
Поле `path` для SATAuto содержит опубликованный адрес, маршрут перенаправления
по числовому ID или `null`, если публичного адреса нет. Относительный путь
открывается на `https://satauto.ru`.

## Запуск с нуля

```sh
./parse init
```

Создайте секрет подписи локально (файл не попадает в Git):

```sh
umask 077
python3 - <<'PY'
from pathlib import Path
import secrets
p = Path('.api.env')
if not p.exists():
    p.write_text('CATALOG_JWT_SECRET=' + secrets.token_urlsafe(48) + '\n')
PY
docker compose run --rm --no-deps api python -m catalog.api create-user admin
docker compose --profile api up -d --wait api
```

Пароль вводится скрыто, минимум 12 символов; хранится только scrypt-хеш с солью.
Файл `.api.env` создаётся с правами 0600 и исключён из Git и Docker-образа.
Swagger открывается на локальном порту 8766.

## Авторизация

В Swagger нажмите **Authorize**, введите username/password. Или отправьте
`POST /token`, Content-Type `application/x-www-form-urlencoded`, поля
`username` и `password`. Полученный `access_token` передавайте как
`Authorization: Bearer <token>`. Срок JWT — 30 минут.
Пользователь, версия токена, подпись, issuer, audience и срок проверяются на каждом запросе.
Смена пароля через `create-user` отзывает выданные токены; `disable-user NAME`
отключает пользователя и также отзывает токены.
Без настроенного секрета авторизация закрыта, API не использует тестовый ключ.

## Каталог и фильтры

- `GET /runs` — прогоны; без `run_id` выбирается последний прогон SATAuto.
- `GET /cars?limit=100` — страница; лимит 1–1000.
- `GET /cars/{car_id}` — одно объявление с исходными данными.
- `GET /fields` — поля, типы и примеры query-параметров.

Каждый нормализованный фильтр отображается отдельным полем в Swagger.

```text
GET /cars?country=CN&country=KR&make=toyota&year_min=2020&year_max=2025
GET /cars?parsed_from=2026-11-19T06:00:00Z&parsed_to=2026-11-19T07:00:00Z
```

Повторяйте имя поля для нескольких допустимых значений. Разные поля соединяются
через AND. Для чисел доступны границы `_min` и `_max`, обе включительные.
Исходные поля можно фильтровать по точному текстовому значению, например
`summary.listing.city=Шанхай`. Путь поддерживает индексы массивов, например
`summary.pricing.steps.0.amount_rub`. Для выдачи исходных объектов
`summary` и `detail` добавьте `include_raw=true`.

`parsed_at` — время последнего сохранённого наблюдения объявления в выбранном
прогоне. Если метки нет, API возвращает `null`. Для `parsed_from` и `parsed_to`
укажите время RFC 3339 с часовым смещением. Начало включается, конец исключается.
В URL кодируйте знак `+` в смещении как `%2B` или используйте UTC с суффиксом `Z`.

Существующий `POST /cars/search` сохраняет поддержку прежнего JSON-тела для
клиентов, использующих операторы `ne`, `isnull` и `contains`.

`next_cursor` из ответа передайте в следующий запрос с теми же условиями фильтрации.
Курсор подписан, закрепляет прогон и условия, срок — 24 часа.
Порядок — `car_id ASC`, используется ключ `(run_id,car_id)`, без глубокого OFFSET.
`has_more=false` означает конец текущей выборки. Подсчёт всего каталога не
выполняется на каждой странице. Во время чтения каталог может обновляться;
это не замороженный снимок, новые ID ниже текущей позиции требуют следующего прохода.
Запросы по произвольным исходным полям могут сканировать весь прогон.
Лимит времени на SQL-запрос составляет 10 секунд, после него API возвращает 503.
