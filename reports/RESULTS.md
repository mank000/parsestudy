## Пакетный импорт · 17 ноября 2026 года

Публичный каталог SATAuto вернул 24 записи в HTML. Проверенная страница не содержит ссылок на выгрузку или на следующую страницу. В опубликованном индексе sitemap 124 файла с адресами и датами изменения. Проверенный XML-файл вернул 1 322 140 байт даже при запросе с неизменившимся `If-None-Match`. В этом замере условный запрос не сократил трафик. [Каталог SATAuto](https://satauto.ru/catalog/) · [Индекс sitemap](https://satauto.ru/sitemap-cars.xml)

Импорт читает обычный NDJSON или NDJSON в gzip потоком и записывает карточки в PostgreSQL через `COPY` без промежуточного обновления каждой записи. Уникальность ID проверяет PostgreSQL. При невалидном, пустом или дублирующемся вводе вся загрузка отменяется.

| --- | ---: | ---: |
| Синтетический NDJSON, прежний пакетный INSERT и UPDATE | 100 000 | 5,824 с |
| Тот же NDJSON, COPY | 100 000 | 2,302 с |
| Тот же набор в gzip, COPY | 100 000 | 2,428 с |
| Синтетический NDJSON в gzip, COPY с фиксацией транзакции | 1 234 397 | 29,920 с |

Для 100 000 записей приведена медиана трёх запусков без фиксации транзакции. Импорт всего объёма проверен в отдельной схеме PostgreSQL с фиксацией и подсчётом всех подробных карточек. Файл весил 20,6 МБ. Время начинается с чтения локального файла и не включает его получение. Все наборы синтетические, сетевых запросов к источнику при импорте ноль. Прогон каталога может отличаться по размеру и времени загрузки.

Для такой скорости с живыми данными нужен пакетный снимок с характеристиками, статусами, цветом и ценами. Команда принимает `.venv/bin/python -m catalog import-export /path/catalog.ndjson.gz`. Согласованный API остаётся вариантом, если поставщик выдаёт данные страницами. ## Повторы HTTP 503 и сопоставление цен · 17 ноября 2026 года

Раньше `Retry-After: 60` задавал срок до следующего запуска, а текущий процесс останавливался. Теперь после HTTP 503 Scrapy повторяет тот же запрос, включая курсор API, XML-файл либо HTML-карточку. В ожидании учитывается `Retry-After`. Если заголовка нет, используется 60 с. Разрешены до двух автоматических повторов и до 120 с ожидания на каждый. Если ожидание дольше или повтор не помог, сбор объявлений останавливается с сохранением курсора или карточек. CarHub продолжает с `crawl --resume ID`, а SATAuto с повторным вызовом `public-html --enrich`. У публичной пробы CarHub при возобновлении остаётся общий лимит в три страницы.

| Прогон | HTTP | Результат | Время |
| --- | ---: | --- | ---: |
| Живой CarHub v2 | 4 × 200 | 300 объявлений списка, 103 812 байт | 5,180 с |
| Живой SATAuto, страница каталога и 4 детали | 6 × 200 | 24 объявления, включая 4 подробных, 431 698 байт | 9,589 с |
| Локальный стенд, ответ 503 с `Retry-After: 60` на второй странице | 3 × 200, 1 × 503 | Повтор того же курсора через 60,010 с. Обе страницы сохранены | 62,392 с |
| Живой SATAuto, полный индекс sitemap | 126 × 200 | 1 234 397 адресов, 124 XML-файла | 352,800 с |

Повторные живые пробы выполнялись в отдельной схеме PostgreSQL. На этих запросах 503 не воспроизвёлся, поэтому 60,010 с измеряют работу клиента на стенде. Исторический `Retry-After: 60` задаёт время до следующей попытки. Это значение не определяет момент восстановления источника или причину ошибки.

### Полный снимок

В публичном sitemap есть адреса и даты изменения. Публичный список CarHub предоставляет характеристики и цены в своём профиле расчёта. В выборках показа цвет не указан. В открытых материалах SATAuto не найден пакетный экспорт с ценами, статусами и цветом. CarHub описывает партнёрский API по ключу и указывает SATAuto среди своих клиентов. Охват, частоту обновления, наличие цвета, профиль цен SATAuto и право на пакетное копирование нужно согласовать до подключения. [Контакты SATAuto](https://satauto.ru/contacts/) · [Подключение CarHub](https://carhubauto.ru/connect/) · [Документация API](https://carhubauto.ru/api/)

После получения согласованного файла используйте `.venv/bin/python -m catalog import-export /path/catalog.ndjson`. Для согласованного API используется `CATALOG_API_ORIGIN`, а при необходимости ключ передаётся через `CATALOG_API_TOKEN`. Сначала проверьте покрытие полей и соответствие расчёта на небольшой порции. В текущем проекте нет подтверждённого источника для полного снимка с этими полями.

Исторически SATAuto вернул HTTP 503 с `Retry-After: 60`. В старом замере CarHub при 503 сообщал о недоступности базы, значение `Retry-After` в том замере не сохранилось. Для следующих ответов 503 парсер пишет HTTP-статус, путь запроса, тип содержимого, `Retry-After` и, если доступно, краткое сообщение из публичного JSON. Если заголовок задаёт время ожидания, сбор объявлений учитывает его при следующем запуске.

## Как сократить запросы

1. **Полный снимок или дельта из SATAuto.** Один согласованный экспорт содержит статусы продажи, характеристики, ссылки на медиа и расчёт по тарифам витрины. Локальный импорт читает NDJSON без HTTP-запросов. Для регулярной выгрузки вариант с изменениями по времени и ID позволит обращаться только за новыми или изменёнными карточками.
2. **Партнёрский API с правами на пакетную выгрузку.** Публичный контракт CarHub позволяет до 100 записей на запрос и публикует лимит 120 запросов в минуту на метод с одного IP. Для масштаба 1 392 282 записей это условно 13 923 запроса списка при максимально заполненных страницах, около 4 ч 15 мин при темпе 1,1 с на запрос и без сетевых сбоев. При отдельной детализации каждого ID по тому же темпу получится около 17,9 суток. Это расчёт по размеру sitemap для планирования. Размер и покрытие реальной выдачи API проверяются отдельно. [Документация CarHub](https://carhubauto.ru/api/) · [Партнёрское подключение](https://carhubauto.ru/connect/)
3. **Только агрегаты.** Для задачи по числу опубликованных карточек достаточно карты сайта. Для числа активных предложений можно использовать фасеты, если владелец источника подтвердит, что счётчики соответствуют той же витрине и фильтру доступности. На проверке фасеты вернули HTTP 500.
4. **Повторные прогоны.** Парсер продолжает согласованный сбор с записанного курсора, не повторяя уже сохранённые страницы. Для периодической проверки sitemap можно использовать объявленный индекс и проверять его версию, а при неизменном XML — использовать HTTP-валидаторы, если источник поддерживает условные запросы.

## Правила доступа и диагностика

Публичный `robots.txt` SATAuto разрешает обход каталога и sitemap, а для внутренних API-путей действует запрет с исключениями для фото. Публичный `robots.txt` CarHub разрешает запрос списка и фасетов, подробный JSON отдельного авто из публичного автоматического режима исключён. CarHub также публикует условия использования с ограничением на массовую выгрузку. Для полного снимка предусмотрены согласованный источник и импорт файла. [Правила SATAuto](https://satauto.ru/robots.txt) · [Правила CarHub](https://carhubauto.ru/robots.txt) · [Условия CarHub](https://carhubauto.ru/offer/)

Пауки соблюдают `robots.txt`, сохраняют причину остановки и учитывают `Retry-After` в API-прогонах. Ответы 500, 502 и 503 при этих проверках сопровождались ошибками источников. По ним нельзя установить срабатывание антибот-защиты.
