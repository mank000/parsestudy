## Как сократить запросы

1. **Полный снимок или дельта из SATAuto.** Один согласованный экспорт содержит статусы продажи, характеристики, ссылки на медиа и расчёт по тарифам витрины. Локальный импорт читает NDJSON без HTTP-запросов. Для регулярной выгрузки вариант с изменениями по времени и ID позволит обращаться только за новыми или изменёнными карточками.
2. **Партнёрский API с правами на пакетную выгрузку.** Публичный контракт CarHub позволяет до 100 записей на запрос и публикует лимит 120 запросов в минуту на метод с одного IP. Для масштаба 1 392 282 записей это условно 13 923 запроса списка при максимально заполненных страницах, около 4 ч 15 мин при темпе 1,1 с на запрос и без сетевых сбоев. При отдельной детализации каждого ID по тому же темпу получится около 17,9 суток. Это расчёт по размеру sitemap для планирования. Размер и покрытие реальной выдачи API проверяются отдельно. [Документация CarHub](https://carhubauto.ru/api/) · [Партнёрское подключение](https://carhubauto.ru/connect/)
3. **Только агрегаты.** Для задачи по числу опубликованных карточек достаточно карты сайта. Для числа активных предложений можно использовать фасеты, если владелец источника подтвердит, что счётчики соответствуют той же витрине и фильтру доступности. На проверке фасеты вернули HTTP 500.
4. **Повторные прогоны.** Парсер продолжает согласованный сбор с записанного курсора, не повторяя уже сохранённые страницы. Для периодической проверки sitemap можно использовать объявленный индекс и проверять его версию, а при неизменном XML — использовать HTTP-валидаторы, если источник поддерживает условные запросы.

## Правила доступа и диагностика

Публичный `robots.txt` SATAuto разрешает обход каталога и sitemap, а для внутренних API-путей действует запрет с исключениями для фото. Публичный `robots.txt` CarHub разрешает запрос списка и фасетов, подробный JSON отдельного авто из публичного автоматического режима исключён. CarHub также публикует условия использования с ограничением на массовую выгрузку. Для полного снимка предусмотрены согласованный источник и импорт файла. [Правила SATAuto](https://satauto.ru/robots.txt) · [Правила CarHub](https://carhubauto.ru/robots.txt) · [Условия CarHub](https://carhubauto.ru/offer/)

Пауки соблюдают `robots.txt`, сохраняют причину остановки и учитывают `Retry-After` в API-прогонах. Ответы 500, 502 и 503 при этих проверках сопровождались ошибками источников. По ним нельзя установить срабатывание антибот-защиты.
