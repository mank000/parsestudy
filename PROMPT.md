# Промпт для ChatGPT

Открой приватный GitHub-репозиторий `mank000/parsestudy` через предоставленный доступ. Если репозиторий из твоего окружения недоступен, попроси архив исходников или доступ к репозиторию. Работай с кодом и запускай проверки. Мне нужен демонстрируемый результат к 13:00 по Барнаулу. Сначала проверь и доведи до показа текущий проект, затем улучшай полноту и производительность. Изменения и выводы подтверждай измерениями. Не публикуй репозиторий, сырые данные выгрузки и секреты.

## Что уже есть

- Scrapy, PostgreSQL, локальный веб-интерфейс в Docker Compose. Главная страница открывается по `http://127.0.0.1:8765/`. В проекте есть сбор публичных HTML-карточек, курсорная пагинация документированного API CarHub, импорт разрешённого NDJSON, полный индекс sitemap SATAuto и отчёты.
- В списке уже есть выбор марки, поиск, пагинация и фильтры по цене, статусу продажи, цвету, стране, году, пробегу и топливу. Аналитика пересчитывается по выборке. Частичные расчёты показаны отдельно от цены, участвующей в сравнениях.
- Замеры и ограничения описаны в `reports/RESULTS.md`. Исторически CarHub возвращал ошибки 500 и 503, SATAuto тоже временами отвечал 503. 17 ноября обычные контрольные запросы к обоим источникам ответили 200. Прогон Scrapy сохранил 300 объявлений CarHub за 5,285 с и 4 HTTP-запроса. Длинный курсор API проходил только после исправления лимита URL у Scrapy. Одна ошибка 503 не подтверждает защиту: проверяй тело ответа, тип содержимого, `Retry-After` и состояние документированного источника.
- В локальной базе предыдущего запуска были 1 241 721 адрес из sitemap и 84 подробные карточки SATAuto. База и выгрузка объявлений в Git не входят. На новом компьютере подтяни данные командами из README или импортируй разрешённый снимок. В индексе у большинства записей есть только адрес, марка и модель из URL.

## Как довести до показа

1. **Проверь запуск на чистой базе.** Запусти `docker compose up -d --build --wait`, инициализируй схему, проверь HTTP 200, фильтр по марке, сочетание «в продаже + диапазон цены», сортировку, пагинацию и пустую выборку. Проверь, что тестовые объявления не появляются в демонстрационной базе. Если источник недоступен, покажи ранее собранный снимок и дату его получения.
2. **Обнови достаточно данных для живой демонстрации.** Проверь документированный CarHub v2 коротким прогоном в пределах поддерживаемого режима. Отдельно проверь публичную HTML-витрину SATAuto. Учитывай правила источника, сохраняй курсор, соблюдай `Retry-After` и ограничивай число повторов. Изображения храни ссылками. Не смешивай покрытие, цены и профили расчёта CarHub с SATAuto. Если нужен весь каталог с полями, запроси согласованный экспорт SATAuto или доступ к партнёрскому API с нужным профилем цен. Импортируй снимок в PostgreSQL и считай полноту по каждому полю. VPS пригоден для согласованного запуска сборщика или размещения демонстрации. Доступы передавай через переменные окружения или менеджер секретов.
3. **Убери лишние запросы.** Сравни выгрузку, курсорные страницы по 100 записей и чтение публичных HTML-карточек. По возможности получай характеристики пакетом. Сохраняй скачанные записи и позицию, дедуплицируй по стабильному ID, загружай детали только для отсутствующих или обновлённых карточек. Проверь поведение при сетевой ошибке, неполном снимке, повторном запуске и изменении схемы ответа. Если есть точка входа для дельты, измерь нагрузку на обновлении.
4. **Сделай аналитику пригодной для защиты.** Покажи отдельно размер индекса, число загруженных объявлений, активные предложения, долю известных цен, пробега и цвета. Для каждой страны и марки покажи размер выборки, число активных, медиану и диапазон цен, распределение по бюджету. Сравнивай цены по сопоставимым моделям, году, топливу и пробегу. Отдельно покажи цену продавца, предварительную и полную стоимость до Владивостока и видимые статьи расчёта. Не делай вывод о рынке по маленькой выборке. Измерь время ответа веб-страницы на полном индексе.
5. **Подготовь короткий сценарий показа.** Открой список, выбери BMW или Toyota, настрой цену и наличие, покажи пересчёт показателей, затем покажи вкладку со всеми адресами и пример подробной карточки. Дай команды запуска, ссылку на локальную страницу и таблицу замеров: источник, время замера, HTTP-запросы, записи, ошибки, полный или частичный прогон. Укажи, какие данные получены с живого источника, а какие использованы только для тестов. Если какая-то часть не успела к показу, назови её и покажи рабочий результат, который можно воспроизвести уже сейчас.

Если времени мало, приоритет такой: запущенный интерфейс, фактические объявления с ценой, фильтры и пересчёт аналитики, воспроизводимый замер. Полную массовую выгрузку показывай только при наличии договорённого источника и проверенного снимка. Таблица ссылок из sitemap сама по себе полной выгрузкой объявлений не является.
